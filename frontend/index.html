O projeto

Sobre o projeto

O Spider Bot é um projeto de robótica que utiliza uma estrutura quadrúpede, servomotores e um microcontrolador ESP8266 para executar movimentos coordenados. Esta página reúne informações sobre os componentes, a montagem, o funcionamento e o código utilizado no robô.

Hardware

Componentes do kit

Conheça os principais elementos utilizados na construção do Spider Bot, conforme a lista do kit recebido.

01

ESP8266

Microcontrolador que executa o firmware e conta com Wi-Fi integrado, usado para criar a rede do robô e receber os comandos de movimento.

02

Servomotores

O robô utiliza oito servomotores, dois por pata, responsáveis por movimentar as articulações das quatro patas.

03

Estrutura mecânica

Peças que formam o corpo (parte de cima, parte de baixo e corpo central), as quatro pernas, as quatro juntas e os dois olhos do robô.

04

Alimentação e conexões

Cabo USB e conexões que alimentam a placa e os servos, de acordo com o manual do kit.

Construção

Montagem passo a passo

A montagem do Spider Bot foi realizada em seis etapas, seguindo as orientações do manual do fabricante. Cada etapa está descrita a seguir.

01

Conferência das peças

Identificamos os componentes recebidos e conferimos a lista do kit: parte de cima, parte de baixo, corpo, quatro pernas, quatro juntas, dois olhos, oito servos, a placa com o ESP8266, os parafusos e o cabo USB.

02

Montagem da estrutura

Montamos a estrutura do robô, formada pelo corpo, pela parte de cima e pela parte de baixo, seguindo a ordem indicada nas instruções oficiais.

03

Centralização dos servos

Antes de instalar os servos, carregamos o programa na placa ESP8266 para levar todos os servos à posição central. Dessa forma, cada servo foi encaixado já centralizado, o que evita erros de posição nas articulações.

04

Instalação dos servos e das patas

Com os servos centralizados, instalamos os oito servos e encaixamos as pernas e as juntas, formando as quatro patas do robô.

05

Conexões e firmware

Conectamos os servos à alimentação da placa e gravamos o firmware v2.0 na ESP8266.

06

Testes

Ligamos o robô, conectamos o celular à rede Wi-Fi Spider Robot e testamos os movimentos, que funcionaram conforme o esperado.

Funcionamento

Controle e comandos

No firmware v2.0, o ESP8266 cria uma rede Wi-Fi própria chamada Spider Robot (senha 12345678) e sobe um servidor web no endereço 192.168.4.1. Cada botão da página de controle envia ao robô uma requisição HTTP do tipo GET, e o firmware executa o movimento correspondente.

01

Movimentos prontos

A requisição /controller?pm=N escolhe um dos 15 movimentos programados no firmware, como andar, girar, deitar e dançar.

02

Servo individual

A requisição /controller?servo=ID&value=ÂNGULO posiciona um servo (ID de 0 a 7) no ângulo informado. É usada nas páginas de calibração.

03

Indicadores digitais

O firmware não envia dados de sensores. Os Gauges desta página mostram os ângulos definidos na interface (demonstração), e não uma medição feita pelo robô.

Firmware

Código Arduino

O firmware v2.0 usa as bibliotecas Servo, EEPROM, ESP8266WiFi, ESP8266WebServer e Adafruit_NeoPixel (olhos de LED). Os trechos abaixo foram simplificados para leitura, mas seguem o código original.

01 / Inicialização

setup()

Liga a serial, os LEDs dos olhos e os servos, cria o ponto de acesso Wi-Fi Spider Robot e inicia a EEPROM e o servidor web.

02 / Movimentos

Servo_PROGRAM_Run()

Executa uma matriz de passos, calculando posições intermediárias a cada 10 ms para o movimento ficar suave.

03 / Comunicação

handleController()

Recebe o parâmetro pm ou o par servo e value enviados pela interface.

Como os movimentos são guardados

Cada movimento é uma matriz com 9 colunas: o ângulo dos 8 servos (ALLSERVOS = 8) e o tempo do passo em milissegundos. O valor de cada ângulo vai de 1 a 180 (PWMRES_Min e PWMRES_Max) e é convertido para a faixa de 400 a 2400 (SERVOMIN e SERVOMAX). A base de tempo é BASEDELAYTIME = 10 ms.

Set_PWM_to_Servo()

Envia um ângulo a um servo. Antes, soma a correção de calibração guardada na EEPROM para aquele servo.

Ver código 
void Set_PWM_to_Servo(int iServo, int iValue)
{
  int NewPWM = iValue + (int8_t)EEPROM.read(iServo);

  NewPWM = map(NewPWM, PWMRES_Min, PWMRES_Max, SERVOMIN, SERVOMAX);

  if (iServo >= 7) {
    GPIO2SERVO.write(NewPWM);
  } else if (iServo >= 6) {
    GPIO4SERVO.write(NewPWM);
  }
  // ... o mesmo padrão continua até o servo 0
}

Servo_PROGRAM_Run()

Percorre os passos da matriz. Em cada passo, repete a cada 10 ms o cálculo da posição intermediária entre a posição atual e a posição alvo de cada servo, e chama Set_PWM_to_Servo().

Ver código 
void Servo_PROGRAM_Run(int iMatrix[][ALLMATRIX], int iSteps)
{
  int INT_TEMP_A, INT_TEMP_B, INT_TEMP_C;

  for (int MainLoopIndex = 0; MainLoopIndex < iSteps; MainLoopIndex++) {
    int InterTotalTime = iMatrix[MainLoopIndex][ALLMATRIX - 1];
    int InterDelayCounter = InterTotalTime / BASEDELAYTIME;

    for (int InterStepLoop = 0; InterStepLoop < InterDelayCounter; InterStepLoop++) {
      for (int ServoIndex = 0; ServoIndex < ALLSERVOS; ServoIndex++) {
        INT_TEMP_A = Running_Servo_POS[ServoIndex];      // posição atual
        INT_TEMP_B = iMatrix[MainLoopIndex][ServoIndex]; // posição alvo

        if (INT_TEMP_A == INT_TEMP_B) {
          INT_TEMP_C = INT_TEMP_B;
        } else if (INT_TEMP_A > INT_TEMP_B) {
          // ... valor diminui: mesma lógica, subtraindo
        } else if (INT_TEMP_A < INT_TEMP_B) {
          INT_TEMP_C = map(BASEDELAYTIME * InterStepLoop, 0, InterTotalTime, 0, INT_TEMP_B - INT_TEMP_A);
          if (INT_TEMP_A + INT_TEMP_C <= INT_TEMP_B) {
            Set_PWM_to_Servo(ServoIndex, INT_TEMP_A + INT_TEMP_C);
          }
        }
      }
      delay(BASEDELAYTIME);
    }
    // ... guarda a posição atual para o próximo passo
  }
}

handleController()

Rota /controller do servidor web. Guarda o movimento pedido em Servo_PROGRAM ou posiciona um servo diretamente, e responde à interface.

Ver código 
void handleController()
{
  String pm = server.arg("pm");
  String servo = server.arg("servo");

  if (pm != "") {
    Servo_PROGRAM = pm.toInt();
  }

  if (servo != "") {
    GPIO_ID = servo.toInt();
    String ival = server.arg("value");
    Set_PWM_to_Servo(GPIO_ID, ival.toInt());
  }

  server.send(200, "text/html", "(pm)=(" + pm + ")");
}

loop()

Atende o servidor web. Se um movimento foi pedido, executa o caso correspondente (a cor dos olhos também muda) e zera Servo_PROGRAM. Sem movimento pedido, os olhos fazem o efeito de respiração com Breath().

Ver código 
void loop(void)
{
  server.handleClient();

  if (Servo_PROGRAM >= 1) {
    switch (Servo_PROGRAM) {
      case 2: // Forward
        // ... define a cor dos olhos (LEDs)
        Servo_PROGRAM_Run(Servo_Prg_2, Servo_Prg_2_Step);
        break;
      // ... demais casos, de 1 a 15
      case 99:
        Servo_PROGRAM_Center();
        delay(300);
        break;
      case 100:
        Servo_PROGRAM_Zero();
        delay(300);
        break;
    }
    Servo_PROGRAM = 0;
  } else {
    Breath();
  }
}

Aplicativo

Spider Bot Control

O Spider Bot Control é a interface dedicada ao controle do robô por dispositivos móveis. O aplicativo é disponibilizado como uma Progressive Web App (PWA) e pode ser instalado na tela inicial de dispositivos compatíveis.

Controle do robô na palma da mão

Abra o aplicativo no celular para instalá-lo e acessar o painel de controle do robô. Os botões de controle do próprio aplicativo são experimentais, porque dependem de o navegador permitir o envio de comandos ao robô.

Acessar Spider Bot Control ↗

Para controlar o robô, o celular precisa estar conectado à rede Wi-Fi Spider Robot, criada pelo firmware.
